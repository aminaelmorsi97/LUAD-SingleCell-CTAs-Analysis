# LUAD Single-Cell RNA-seq Analysis: CTAs in Metastatic Progression

## 🧬 Project Overview
This repository contains the bioinformatic analysis pipeline for investigating **Cancer-Testis Antigens (CTAs)** expression dynamics during lung adenocarcinoma (LUAD) metastatic progression.

## 📊 Dataset Summary
* **Primary Dataset (GSE131907):** 208,506 single cells.
* **Malignant Subset:** 31,136 cells (`tLung`, `mBrain`, `mLN`, `PE`).

## 📁 Repository Structure
* `scripts/`: R scripts for data processing and CTA expression analysis.
* `results/`: Output figures and target candidate gene evaluations.
